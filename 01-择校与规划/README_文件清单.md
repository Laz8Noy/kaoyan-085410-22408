## 三、推荐使用顺序

1. 先看 `085410_22408_择校与规划_20260820.xlsx` 的「院校总览」确定冲稳保；
2. 打开 `每日学习打卡表` 开始第1周打卡；
3. 数据结构用 `GitHub笔记/Awesome-408/数据结构/王道笔记/` 的markdown配合王道书；
4. 计组/OS/计网参考 `GitHub笔记/LYuYang61-408/` 的王道PDF（带书签）+湖科大PPT；
5. 10月报名前用 `408考研终极版` 的院校大全再核对一遍；
6. 复试前看 `复试机试准备清单.md`。
