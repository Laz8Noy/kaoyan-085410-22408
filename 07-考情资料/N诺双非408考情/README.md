# 双非院校 408 考情（N诺数据 2026）提取

来源：`双非院校408考情分析_N诺数据.xlsx`（N诺考研 noobdream.com），170 所双非、1434 条 408 考情记录，覆盖 2015/2021/2023-2026。

## 文件
| 文件 | 内容 |
|---|---|
| `双非408考情_2026提取.xlsx` | Sheet1 2026年408系明细（专业级：复试线/408均分/政治英数均分/录取率/报录比）；Sheet2 每校聚合（专业数/最高均408分/线区间/平均录取率/淘汰率） |
| `双非408考情_2026_310分档.md` | 过滤复试线 250-330 的 408 系专业（与你 310 分档相关） |

## 价值
- 补齐终极版缺的 **408 均分、政治/英语/数学单科均分、录取率、报录比** 维度
- 可用于：判断某双非 408 校"好不好考"（看 408均分/录取率）、复试线是否在你的 310 档
- 与王道考情（复试人数/分数段）、终极版（复试线/均分）三者交叉核对
